# Santhosh Reddy Papireddy — portfolio

Static site for GitHub Pages. No build step.

## Publish (about 10 minutes)
1. Create a free account at github.com (pick your username, e.g. `santhoshreddy39`).
2. Click **New repository**. Name it exactly `<your-username>.github.io` (e.g. `santhoshreddy39.github.io`). Set it to **Public**. Create.
3. On the new repo page click **uploading an existing file**. Drag in `index.html` and the whole `assets` folder. Click **Commit changes**.
4. Go to **Settings → Pages**. Under "Build and deployment", Source = **Deploy from a branch**, Branch = **main**, folder **/(root)**. Save.
5. Wait 1–2 minutes. Your site is live at `https://<your-username>.github.io`.

## Updating later
- Edit text: open `index.html` on GitHub, click the pencil icon, change, **Commit changes**. Live in ~1 minute.
- New resume: upload a new file named `assets/Santhosh_Reddy_Resume.pdf` (same name replaces the old one).
- New photo: replace `assets/santhosh-reddy.jpg`.

## Custom domain (optional)
Buy a domain (e.g. santhoshreddy.dev), then in **Settings → Pages → Custom domain** enter it and follow GitHub's DNS instructions. Tick **Enforce HTTPS**.
